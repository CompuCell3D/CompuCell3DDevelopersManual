Screenshot and Diagram Assets
=============================

Images for this chapter belong in this directory so the chapter can be moved
to another documentation project without changing the text layout.

The text is designed to work without screenshots. Candidate assets for a
future revision are:

* ``project_layout.png`` showing the files in a compiled-steppable project;
* ``build_command.png`` showing a successful native build;
* ``player_output.png`` showing lifecycle messages from a running demo;
* ``lifecycle.svg`` showing the callback sequence.

Screenshots should use generic paths or redact local usernames and machine
specific directories. Prefer SVG diagrams for relationships and PNG images
for application screenshots. Each image should be referenced with a relative
path from the page that uses it.
